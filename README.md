Sistema de Inventario en PYTHON

Este proyecto es una aplicación de consola desarrollada en Python, que permite gestionar un inventario de productos utilizando una base de datos SQLite. 
Incluye funciones para crear, leer, actualizar y eliminar (CRUD) productos, además de reportes de stock.

Características principales:

✔ Agregar productos
✔ Mostrar todos los productos
✔ Buscar producto por ID
✔ Actualizar producto
✔ Eliminar producto
✔ Reporte de productos con bajo stock
✔ Uso de SQLite como base de datos local
✔ Colores en consola gracias a colorama
